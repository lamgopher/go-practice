## Вопросы для самопроверки

1. Какие проблемы Google решал созданием Go? Почему неиспользуемые переменные и импорты — ошибка компиляции?
2. Сколько видов цикла в Go? Как записать `while` и `do-while`?
3. Нужен ли `break` в `switch`? Что делает `fallthrough` и проверяет ли он условие следующей ветки?
4. Чем `switch x { case ... }` отличается от `switch { case cond: ... }`?
5. Назовите четыре способа объявить переменную. Где нельзя использовать `:=`?
6. Каково zero value у `int`, `float64`, `bool`, `string`, массива, слайса, map, структуры, указателя?
7. Чем `byte` отличается от `rune`? Что вернёт `len("привет")`?
8. Что такое нетипизированная константа? Как работает `iota`? Сбрасывается ли она в новом блоке `const`?
9. Из каких трёх полей состоит слайс? Чем `len` отличается от `cap`?
10. Для `arr := [5]int{1,2,3,4,5}`: чему равны значения, `len` и `cap` у `arr[1:3]`, `arr[:2]`, `arr[2:]`, `arr[1:3:3]`?
11. Что возвращает `append` и почему результат всегда надо присваивать? Когда происходит реаллокация и как растёт ёмкость?
12. Объясните пример с новостями и рекламой: почему `append` в одном слайсе испортил другой и как это лечится?
13. Чем `make([]int, 10)` отличается от `make([]int, 0, 10)`? Когда второй вариант предпочтительнее?
14. Как отличить «ключа нет» от «значение равно нулю» в map?
15. Что произойдёт при чтении из nil-map? При записи?
16. Гарантирован ли порядок обхода map? Почему слайс не может быть ключом, а массив может?
17. Как в Go устроена приватность?
18. «В Go всё передаётся по значению» — тогда почему функция может изменить элементы переданного слайса, но не может
    изменить его длину для вызывающего?
19. Чем метод с получателем `(p Point)` отличается от `(p *Point)`? Почему рекомендуют не смешивать их в одном типе?
20. Можно ли сложить `int` и `type RichInt int` без приведения?
21. Когда локальная переменная оказывается в куче?

## Практика

Каждое задание — отдельный `main.go`, запуск через `go run`. Сначала **запишите прогноз** вывода, потом запускайте.
Перед практикой пройдите четыре теста из `materials/` (ответы спрятаны в `<details>`).

### Задание 1. Управляющие конструкции

1. FizzBuzz от 1 до 30 тремя способами: `if/else`, `switch` без аргумента, `switch` с `fallthrough` (там, где он уместен).
2. Функция `grade(rating int) string` из примера лектора: `>= 90` premium, `>= 70` good, `>= 50` warning, иначе bad —
   через `switch` без аргумента.
3. Таблица умножения 9×9 вложенными циклами; прервите **внешний** цикл по метке, как только произведение превысит 50.
4. Эмуляция `do-while`: читать числа из stdin, пока не введут 0, вывести сумму.

### Задание 2. Zero value и константы

1. Объявите через `var` без инициализации по одной переменной каждого типа из вопроса 6 и выведите их через `%#v`.
2. Объявите `Weekday` на базе `int` с константами через `iota` и методом `String()`.
3. Объявите права `Read`, `Write`, `Exec` через `1 << iota`; напишите `Has(perm, flag) bool`. Проверьте `Read|Exec`.
4. Объясните, почему компилируется `var x int64 = 10 / 3.0 * 3` или почему нет — проверьте.

### Задание 3. Слайсы под микроскопом

1. Воспроизведите эксперимент лектора: в цикле 20 раз `append` по одному элементу, после каждого шага печатайте
   `len`, `cap` и адрес первого элемента (`%p`, `&s[0]`). Отметьте шаги, где адрес меняется.
2. Воспроизведите баг с новостями:
   ```go
   news := []string{"n1", "n2", "n3", "n4", "n5"}
   showMainPage(news[:3]) // внутри: append(news, "реклама")
   showAll(news)
   ```
   Убедитесь, что `n4` испорчена. Исправьте двумя способами: трёхиндексным срезом и копированием (`copy`).
3. Напишите `Insert(s []int, i int, v int) []int` и `Remove(s []int, i int) []int`. Проверьте, что исходный слайс
   вызывающего не портится (или задокументируйте, что портится).
4. Напишите `Chunk(s []int, n int) [][]int`, разбивающую слайс на пачки по `n`. Затем допишите в первую пачку элемент
   через `append` и посмотрите на вторую. Исправьте.
5. Чем отличаются `var s []int`, `s := []int{}` и `s := make([]int, 0)`? Сравните с `nil`, выведите `len`, сериализуйте
   в JSON (`encoding/json`).

### Задание 4. Map

1. Подсчёт частоты слов в строке; вывод, отсортированный по убыванию частоты (понадобится слайс и `sort`).
2. Запустите обход одной map пять раз подряд — убедитесь, что порядок меняется.
3. `var m map[string]int; m["a"] = 1` — что будет? Почините.
4. Реализуйте множество строк через `map[string]struct{}` с операциями `Add`, `Has`, `Delete`.
5. Сделайте ключом map массив `[2]int` (координаты клетки). Попробуйте заменить на `[]int` — прочитайте ошибку.
6. Группировка: из `[]Person{Name, City}` получить `map[string][]string` город → имена.

### Задание 5. Функции и «ссылочность»

Для каждого пункта — прогноз, затем запуск:

```go
func incr(i int)            { i++ }
func incrPtr(i *int)        { *i++ }
func zero(s []int)          { for i := range s { s[i] = 0 } }
func grow(s []int)          { s = append(s, 1) }
func fill(m map[string]int) { m["x"] = 1 }
func zeroArr(a [3]int)      { a[0] = 0 }
func rename(p Point)        { p.X = 100 }
```

Затем напишите:

1. `Sum(first int, rest ...int) int`; вызовите с распаковкой слайса `Sum(1, nums...)`.
2. `Divide(a, b float64) (result float64, err error)` с именованными результатами.
3. `Apply(nums []int, f func(int) int) []int` и вызовите с анонимной функцией.
4. `Counter() func() int` — замыкание, возвращающее возрастающие числа.

### Задание 6. Структуры и методы

1. Тип `Point{X, Y float64}` с методами `Abs()` (по значению) и `Scale(k float64)` (по указателю). Убедитесь, что
   `Scale` с получателем по значению «не работает», и объясните почему.
2. Тип `Stack` на базе `[]int` с `Push`, `Pop() (int, bool)`, `Len`.
3. Тип `Celsius float64` и `Fahrenheit float64` с методами конвертации. Попробуйте сложить их напрямую.
4. Сравните через `==` две структуры: только со скалярными полями и со слайсом внутри. Что говорит компилятор?
   Сравните вторую через `reflect.DeepEqual`.
5. Выведите структуру через `%v`, `%+v`, `%#v`.

### Задание 7. Строки

1. Для строки `"Привет, Go"` выведите `len`, число рун, пройдите её через `for i := 0; i < len(s); i++` и через
   `for i, r := range s` — объясните разницу в индексах.
2. Напишите `Reverse(s string) string`, корректно работающую с кириллицей.
3. Попробуйте `s[0] = 'x'`. Сделайте то же через `[]byte` и `[]rune`.
