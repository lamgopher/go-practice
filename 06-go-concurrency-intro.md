## Практика

Все примеры запускайте с детектором гонок: `go run -race .` / `go test -race ./...`.

### Задание 1. Прогноз поведения

Для каждого фрагмента: прогноз → запуск → объяснение.

```go
// A
func main() {
    go fmt.Println("hello")
}

// B
func main() {
    ch := make(chan int)
    ch <- 1
    fmt.Println(<-ch)
}

// C
func main() {
    var ch chan int
    go func() { ch <- 1 }()
    fmt.Println(<-ch)
}

// D
func main() {
    ch := make(chan int, 2)
    ch <- 1; ch <- 2
    close(ch)
    for i := 0; i < 4; i++ {
        v, ok := <-ch
        fmt.Println(v, ok)
    }
}

// E
func main() {
    var wg sync.WaitGroup
    for i := 0; i < 3; i++ {
        go func(wg sync.WaitGroup) { defer wg.Done(); wg.Add(1) }(wg)
    }
    wg.Wait()
    fmt.Println("done")
}
```

### Задание 3. Базовые паттерны

1. **Generator**: `gen(nums ...int) <-chan int` — канал закрывает сама функция.
2. **Pipeline**: `sq(in <-chan int) <-chan int`; соберите `gen → sq → sq → print`.
3. **Fan-out / fan-in**: запустите три `sq` на одном входном канале и объедините результаты функцией
   `merge(cs ...<-chan int) <-chan int` (WaitGroup + закрытие выходного канала после завершения всех).
4. Убедитесь через `runtime.NumGoroutine()`, что после завершения конвейера горутин не осталось.

### Задание 6. Пул воркеров двумя способами

### Задание 7. Graceful shutdown

Программа: продюсер раз в 200 мс кладёт число в канал, консьюмер печатает. По Ctrl+C:

- продюсер перестаёт генерировать и закрывает канал;
- консьюмер дочитывает остаток и завершается;
- `main` дожидается обоих и печатает «bye».

Проверьте, что ни одно значение не потерялось (счётчики отправленных и полученных).
