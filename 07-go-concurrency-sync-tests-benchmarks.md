### Задание 2. Ловушки мьютекса

Для каждого: прогноз → запуск → объяснение → исправление.

```go
// A: копирование
type Counter struct { mu sync.Mutex; n int }
func (c Counter) Inc() { c.mu.Lock(); defer c.mu.Unlock(); c.n++ }

// B: рекурсивный захват
func (c *Counter) Get() int { c.mu.Lock(); defer c.mu.Unlock(); return c.n }
func (c *Counter) IncAndGet() int { c.mu.Lock(); defer c.mu.Unlock(); c.n++; return c.Get() }

// C: порядок захвата
func transfer(from, to *Account, sum int) {
    from.mu.Lock(); defer from.mu.Unlock()
    to.mu.Lock();   defer to.mu.Unlock()
    from.balance -= sum; to.balance += sum
}
// вызывается одновременно: transfer(a, b, 1) и transfer(b, a, 1)
```

Проверьте A командой `go vet`.
